# Мебелировщик Pro 6.0

Профессиональная программа для проектирования корпусной мебели «от комнаты до цеха»:
план помещения, 3D-сцена для клиента, конструктор шкафов и кухонь, деталировка,
карты раскроя ЛДСП, смета в трёх видах (основная / по изделиям / для клиента),
освещение с расчётом люмен, рендер-снимки, экспорт OBJ/DXF.

## Как открыть

Приложение — один файл `index.html`. Ничего устанавливать не нужно:

- **Онлайн:** если в репозитории включён GitHub Pages — просто откройте ссылку
  `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/` в любом браузере (компьютер, iPad, телефон).
- **Офлайн:** скачайте `index.html` и откройте в Chrome/Safari/Edge.
  При первом запуске нужен интернет (подгружаются библиотеки React и Three.js).

На iPad: открыть ссылку в Safari → «Поделиться» → «На экран “Домой”» — появится
иконка, приложение запускается на весь экран как обычная программа.

## Возможности

- Комната с окнами, дверями, батареями, розетками; стены тянутся мышью
- Каталог: кухня, спальня, санфаянс, свет, примитивы + поиск
- Магнит как в PowerPoint (край-к-краю, центр-к-центру, направляющие), отключаемый
- Перетаскивание мебели на плане и прямо в 3D, ортовиды (сверху/спереди/сбоку)
- Двери открываются кликом: распашные с видимыми петлями, купе, ящики
- Полки и штанги по секциям, задняя стенка ХДФ/ЛДСП/без, ручки со схемой присадки
- Рулетка и авторазмеры выносными линиями в 2D и 3D, развёртки стен
- Светильники с люменами, тени, проверка нормы освещённости, рендер PNG
- Деталировка с крепежом, CSV, печать; раскрой листов 2800×2070 с КПД
- Смета: валюта USD/UZS/RUB/EUR с ручным курсом, зарплата, НДС, доставка
- ИИ-разбор фото интерьера с переносом текстур (работает при запуске внутри Claude)
- Сохранение/открытие проекта, вставка гарнитуров, экспорт OBJ+MTL и DXF
